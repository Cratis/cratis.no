# Reference material

## `design-concept.html`

An early single-page design concept for Cratis, produced before this site
was built. Preserved here because the brand and review documents refer to
it, and the original lived in a Downloads folder that will not survive.

**Open it in a browser.** It is the reference for *feel*: dark, vivid,
atmospheric, and deliberately non-technical.

What it established, and what this site carries forward:

- A **rotating word in the headline** — "Build software that *remembers /
  explains / replays / reveals / evolves / scales*". Each word is a
  different reason to care, which is how an abstract product shows what it
  does when there is nothing to photograph.
- A **vivid multi-colour palette** — purple, teal, yellow, orange.
- An **abstract orbital visual** that reads as energy rather than data.
- **Fraunces italic** as the accent face against Inter.
- Near-black ground, hairline card grids, numbered navigation.

**It also contains factual errors that must not be reproduced:**

- It claims a **Go SDK for Chronicle**. There is no Go client.
- Its **support tiers are copied verbatim from JasperFX** — the same
  10/20/50 consulting hours and 48/36/24 hour response times.
- It uses "ecosystem" and "AI-infused", both on the do-not-say list.
- Its tagline is *"Model the truth. Generate the rest."* — which
  contradicts the product: Cratis Stage performs the model at runtime
  rather than generating code from it.

Take the feel. Verify the facts.
