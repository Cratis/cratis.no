Why structure matters

Faster generation should not mean faster drift.

A general assistant can produce plausible code quickly. Cratis gives it explicit boundaries so the result still looks like your system and still has to pass the same gates as human work.

Model before implementation

Commands, facts, streams, state views, reactions and compliance questions become explicit before an agent starts creating files.

Trust by construction

Released. Ready to install. Clear about limits.

Cratis AI has a supported public release, starting with v1.0.0. Install the @cratis/pi npm package, use Cratis's own GitHub-hosted plugin marketplaces for Claude Code, Codex, GitHub Copilot and Cursor, or choose the cratis CLI's managed installation. Project context stays with the project.

Marketplace plugins track Cratis/AI's main branch, not a pinned release. The Pi package is versioned; there is no separately published, versioned package per profile. These are Cratis-hosted marketplaces, not a claim of vendor-curated central listings.

OpenCode is supported through managed installation, not a plugin marketplace entry. Kiro, Junie and Gemini are not supported. Installation does not replace compiler gates, specifications, CI or human review.
